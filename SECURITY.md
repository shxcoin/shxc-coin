# SHXC Coin — Security & Verification

Before interacting with SHXC, verify:
1. The blockchain network.
2. The official contract address or asset identifier.
3. The destination wallet/payment instructions.
4. The requested amount.
5. That the selected network is supported for the intended transaction.

Use [NETWORKS.md](NETWORKS.md) and https://shshops.com/shxccoin

## Do not trust the ticker alone
Third parties can create assets using `SHXC`, `SHXC Coin`, or similar names. Match the network and full identifier against an official source.

## Multichain warning
An official deployment on one network does not automatically establish a bridge, identical liquidity, identical market price, identical wallet/merchant support, or compatibility with every S.H SmartHub payment route.

Blockchain transfers may be irreversible. Verify all transaction details before submission.
